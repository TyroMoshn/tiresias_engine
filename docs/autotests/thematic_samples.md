# Памятка: Тематические тестовые подборки для проверки качества рекомендаций

В этом документе зафиксированы отобранные пользователем коллекции постов (Ground Truth / Seed Sets) для семантической валидации качества работы движка досок, выделения ключевых тегов (Salient Tags) и рекомендаций «More Like This Board».

> [!NOTE]
> Локальный датасет зафиксирован на определенной дате отсечки (cut-off). Более свежие публикации, отсутствующие в офлайн-индексе, сервер автоматически логирует с предупреждением (`WARNING: Post ID {id} not found in index`) и продолжает работу с валидными ID выборки.
