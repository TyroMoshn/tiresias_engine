# Модуль `autotest/visualize_post2vec_cpu.py` (Техническая документация)

## 1. Назначение и Архитектурная роль
Модуль `visualize_post2vec_cpu.py` реализует сквозной пайплайн нелинейного снижения размерности, топологической кластеризации и генерации интерактивного аналитического дашборда для исследования 128-мерного пространства эмбеддингов постов (`post2vec`).

Результатом работы является автономный интерактивный HTML-файл с визуализацией на основе **Bokeh** и **Datashader**, поддерживающий зуммирование, фильтрацию, инспекцию метаданных при наведении курсора и переход по клику на оригинальную публикацию.

## 2. Математический пайплайн снижения размерности

### 2.1. Сэмплирование из индекса FAISS (`load_sample_vectors`)
Из индекса `post2vec_faiss.index` извлекается равномерная случайная выборка векторов $X \in \mathbb{R}^{S \times 128}$ (по умолчанию $S = 300\,000$) методом реконструкции `index.reconstruct_batch` и `rng.choice(replace=False)`. Идентификаторы строк сопоставляются с глобальными `post_id` через `post2vec_faiss_ids.parquet`.

### 2.2. Нелинейная проекция: UMAP
Для редукции размерности из $\mathbb{R}^{128} \to \mathbb{R}^{2}$ применяется алгоритм **UMAP** (Uniform Manifold Approximation and Projection):
- Метрика расстояния: косинусная (`metric="cosine"`).
- Число локальных соседей: $k = 15$ (`n_neighbors`).
- Минимальное расстояние между точками в проекции: $\delta = 0.05$ (`min_dist`), обеспечивающее плотную группировку семантически близких тем.
- Оптимизация памяти: `low_memory=True`, задействование всех доступных ядер CPU (`n_jobs=-1`).

### 2.3. Плотная кластеризация: HDBSCAN
На двумерных координатах $(x, y)$ выполняется иерархическая кластеризация на основе плотности **HDBSCAN** (Hierarchical Density-Based Spatial Clustering of Applications with Noise):
- Параметр минимального размера кластера: `min_cluster_size = 60`.
- Кластер `-1`: шум (посты в зонах низкой плотности пространства, не принадлежащие выраженным жанрам или сюжетам).
- Кластеры $0, 1, 2 \dots K$: устойчивые семантические макро-кластеры (например, определенный фэндом, стилистика рисовки, персонажи или сеттинг).

## 3. Обогащение метаданными и извлечение ключевых тегов
Для каждого обнаруженного кластера вычисляются доминирующие теги (Cluster Top Tags):
1. Из `posts_parquet` для сэмплированных постов подтягиваются `fav_count` и `score`, а денормализованная строка тегов `tag_string` реконструируется путем джоина `post_tags_parquet` с `tags_dict.parquet`.
2. Частоты слов внутри кластера агрегируются через `collections.Counter`.
3. Топ-12 самых частых тегов кластера конкатенируются в строку описания кластера (`cluster_top_tags`).

## 4. Архитектура рендеринга больших данных (Datashader + Bokeh)

Отображение 300 000 векторных точек напрямую в DOM браузера через SVG/Canvas приводит к зависанию клиента. Архитектура визуализации разделена на два слоя:

1. **Фоновый растровый слой (Datashader)**:
   Все 300 000 точек динамически агрегируются в 2D-гистограмму плотности на стороне Python и рендерятся в растровое изображение высокого разрешения (`ImageRGBA`). Это обеспечивает $O(1)$ нагрузку на браузер независимо от числа точек.
2. **Интерактивный оверлей (Overlay Glyph Layer)**:
   Небольшая репрезентативная фракция точек (`overlay_frac = 0.02`, порядка 6 000 постов) накладывается поверх растра в виде векторных маркеров Bokeh с поддержкой инструментов:
   - `HoverTool`: всплывающая карточка с ID поста, номером кластера, оценкой, лайками, ключевыми тегами кластера и тегами поста.
   - `TapTool` + `OpenURL`: при клике на точку браузер открывает страницу публикации по шаблону `url_prefix + "@post_id"`.
   - Интерактивные виджеты Bokeh: `RangeSlider` и спиннеры для фильтрации по `score`, чекбокс для отображения плотности фона (Datashader), слайдеры для настройки размера и толщины обводки точек, а также спиннеры для изменения размеров холста (canvas size).

Выходной артефакт сохраняется как самодостаточный HTML: `features/post2vec_umap_hdbscan_cpu_with_meta.html`.

## 5. Интерфейс командной строки (CLI)
Скрипт принимает следующие аргументы:
- `--features-dir`: путь к директории с `post2vec_faiss.index` и `post2vec_faiss_ids.parquet`.
- `--data-root`: корневая директория с `posts_parquet/`, `post_tags_parquet/`, `tags_dict.parquet`.
- `--sample-size`: размер случайной выборки векторов (по умолчанию `300000`).
- `--min-cluster-size`: минимальный размер кластера для HDBSCAN (по умолчанию `60`).
- `--overlay-frac`: доля точек для интерактивного оверлея (по умолчанию `0.02`).
- `--seed`: сид генератора случайных чисел (по умолчанию `42`).
- `--output`: имя выходного HTML файла (по умолчанию `post2vec_umap_hdbscan_cpu_with_meta.html`).
- `--url-prefix`: префикс URL для перехода к постам по клику.
