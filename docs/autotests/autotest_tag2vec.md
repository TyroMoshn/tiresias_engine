# Модуль `autotest/autotest_tag2vec.py` (Техническая документация)

## 1. Назначение
Модуль `autotest_tag2vec.py` является диагностической утилитой и тестовым CLI-интерфейсом для инспекции семантического качества векторных представлений тегов, сформированных на этапе `tag2vec_stage`.

Утилита позволяет:
- Разрешать строковые имена тегов в числовые `tag_id` без учета регистра (case-insensitive) и с учетом графа синонимов (`tag_aliases.csv`).
- Читать и выводить метаданные обучения (`tag2vec_meta.json`), без строгой валидации.
- Инспектировать предварительно вычисленный k-NN граф (`tag2vec_knn.parquet`).
- Вычислять косинусных соседей «на лету» (On-the-Fly Cosine Search) прямо из матрицы эмбеддингов `tag2vec.parquet`, если тег отсутствует в предварительно рассчитанном топе.
- Опционально триггерить изолированный пересчет шага Tag2Vec через вызов субпроцесса (`run_recompute`).

## 2. Архитектура и функциональные компоненты

### 2.1. Разрешение идентификаторов тегов (`resolve_tag_ids`)
1. Проверка на числовой литерал (`name_or_id.isdigit()`): прямой возврат `tag_id`.
2. Поиск точного совпадения в `tags.parquet` / `tags_dict.parquet` в нижнем регистре.
3. Разрешение через транзитивный граф активных алиасов `load_alias_map_if_any`: рекурсивное сжатие путей синонимов $A \to B \to \dots \to \text{Canon}$.
4. Режим подсказок (`--suggest`): фильтрация подстроки (`str.contains`) для выдачи похожих по написанию тегов при опечатках.

### 2.2. Загрузка векторов и расчет k-NN (`compute_knn_from_vecs`)
Если в `tag2vec_knn.parquet` нет сохраненных соседей для запрашиваемого тега:
1. Матрица векторов загружается в память в виде массива NumPy типа `float32`.
2. Выполняется L2-нормализация: $M_{\mathrm{norm}} = M / (\|M\|_2 + \varepsilon)$.
3. Вычисляется вектор косинусных сходств через матрично-векторное умножение:
   $$s = M_{\mathrm{norm}} \cdot m_q^T \in [-1, 1]^V$$
4. Диагональный элемент $s[q]$ маскируется значением $-\infty$.
5. Быстрая частичная сортировка через `np.argpartition(-s, k)` со сложностью $O(V)$ отбирает $k$ максимальных элементов, после чего выполняется точная сортировка топ-$k$ среза.

### 2.3. Форматированный вывод
Результаты выводятся в виде ранжированного списка с сопоставлением числового ID и строкового имени из артефакта словаря:
```text
 1. tag_id=    1234  name=dragon                         sim=0.8921
 2. tag_id=    5678  name=scales                         sim=0.8145
```

## 3. Параметры командной строки
```bash
python autotest_tag2vec.py \
    --root-data "data" \
    --tag "wolf" \
    --topk 10 \
    --suggest \
    --recompute \
    --tag2vec-dim 128 \
    --tag2vec-min-df 200 \
    --tag2vec-source merge \
    --tag2vec-pool-alpha 0.5 \
    --tag2vec-shift 0.0 \
    --tag2vec-knn-k 32
```
