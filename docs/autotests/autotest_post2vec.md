# Модуль `autotest/autotest_post2vec.py` (Техническая документация)

## 1. Назначение и Архитектурная роль
Модуль `autotest_post2vec.py` реализует комплексную валидацию артефактов векторных представлений публикаций (`post2vec.parquet`, `post2vec_faiss.index`, `post2vec_faiss_ids.parquet`), проверку математической воспроизводимости векторов и интерактивный поиск семантически похожих публикаций по ID.

Модуль спроектирован по принципу модульного тестового сьюта (`Suite`, `CheckResult`), возвращает код завершения `0` при успешной верификации или `1` при обнаружении регрессий.

## 2. Комплекс проверок (Verification Pipeline)

### 2.1. Целостность таблицы векторов (`inspect_post2vec`)
- Извлекает схему данных `post2vec.parquet` для логирования.
- Проверяет инвариант строгой уникальности первичного ключа: $\mathrm{unique}(\text{post\_id}) == \text{rows}$.
- Считывает размерность векторов $D$ (типовое значение 128) и тип элементов.
- Считает контрольную сумму 64-битных хешей идентификаторов (`hash_sum`) через streaming engine Polars.

### 2.2. Целостность маппинга индексов FAISS (`inspect_ids`)
- Извлекает метаданные из `post2vec_faiss_ids.parquet`.
- **Инвариант непрерывности адресации**: проверяет, что поле `row` представляет собой строгую непрерывную последовательность без пропусков:
  $$\min(\mathrm{row}) == 0, \quad \max(\mathrm{row}) == N - 1, \quad \mathrm{unique}(\mathrm{row}) == N$$
- Сверяет число строк и контрольную сумму хешей `post_id` с файлом `post2vec.parquet`.

### 2.3. Целостность бинарного индекса FAISS (`inspect_index` / `inspect_sq8_index`)
- Загружает файлы `post2vec_faiss.index` и `post2vec_sq8.index` (при наличии) через `faiss.read_index`.
- Проверяет согласованность счетчика векторов: $\text{idx.ntotal} == N$.
- Проверяет размерность пространства поиска: $\text{idx.d} == D$.
- Для SQ8 индекса дополнительно проводится бенчмарк скорости поиска (целевая задержка $\le 150$ мс для сканирования) и проверяется размер файла (целевой размер $\le 850$ МБ).

### 2.4. Выборочная математическая верификация (`verify_samples`)
Ключевой тест, гарантирующий математическую корректность пайплайна без слепого доверия к сохраненным файлам.
1. Выбираются $S$ равномерно распределенных по всему датасету строк (с шагом $N / S$).
2. Из `post2vec.parquet` загружаются сохраненные векторы $v_{\mathrm{actual}}$.
3. **Независимая реконструкция "с нуля"**:
   - По `post_id` из `post_tags_parquet` считываются исходные теги поста.
   - Из `tag2vec.parquet` загружаются соответствующие векторы тегов $e_t$.
   - Из `tags.parquet` (или `tags_dict.parquet`) считываются веса $\mathrm{IDF}(t)$ и категории.
   - Вычисляется теоретический ожидаемый вектор с учетом весов категорий (`DEFAULT_CATEGORY_WEIGHTS`):
     $$v_{\mathrm{expected}} = \mathrm{normalize}\left(\sum_{t} \mathrm{IDF}(t) \cdot w_{\mathrm{cat}}(t) \cdot e_t\right)$$
4. **Контроль L2-погрешности**:
   Вычисляется евклидово расстояние между фактическим и эталонным вектором:
   $$\|v_{\mathrm{actual}} - v_{\mathrm{expected}}\|_2 \le \text{tolerance} \quad (5 \times 10^{-4})$$
5. **Тест самопоиска в FAISS (Self-Retrieval Consistency)**:
   Вектор $v_{\mathrm{actual}}$ подается на вход FAISS `index.search(q, 1)`. Индекс обязан вернуть в качестве ближайшего соседа ту же самую строку `row_id` с косинусным сходством $1.0000 \pm 0.0005$.

## 3. Интерактивный режим поиска похожих постов (`--query-post`)
Позволяет протестировать функционал рекомендации похожих публикаций:
```bash
python autotest_post2vec.py \
    --root-data "data" \
    --query-post 543210 \
    --topk 10 \
    --sample 5 \
    --tolerance 0.0005 \
    --include-query
```
- `--sample`: Количество равномерно распределенных постов для валидации векторов (по умолчанию 5).
- `--tolerance`: Допустимая L2-погрешность при сравнении векторов (по умолчанию 5e-4).
- `--include-query`: Включает сам пост запроса в выдачу FAISS (по умолчанию он исключается).
- Извлекает вектор поста, подает в FAISS, исключает сам пост запроса и через `post2vec_faiss_ids.parquet` возвращает ранжированный список `post_id` с косинусными оценками сходства:
```text
 1. post_id=581290  row=412981  sim=0.9124
 2. post_id=601421  row=492104  sim=0.8872
```
