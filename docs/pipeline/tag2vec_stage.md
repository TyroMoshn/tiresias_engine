# Модуль `tag2vec_stage.py` (Техническая документация)

## 1. Назначение и Теоретический фундамент
Модуль `tag2vec_stage.py` (точка входа: `step_tag2vec(cfg: Config) -> None`) реализует обучение плотных семантических векторных представлений тегов (Embeddings) в пространстве $\mathbb{R}^{D}$ (по умолчанию $D = 128$).

Архитектура опирается на классическую теорему Леви и Голдберга (Levy & Goldberg, 2014) об эквивалентности матричной факторизации PPMI-матрицы модели Skip-gram with Negative Sampling (Word2Vec). Вместо медленного стохастического градиентного спуска (SGD) через нейросеть используется точная спектральная декомпозиция разреженной матрицы через усеченное сингулярное разложение (Truncated SVD).

## 2. Математический пайплайн

### 2.1. Объединение источников графа
На вход поступают два независимых графа связности тегов:
1. $W_{\mathrm{pmi}}$ из `tag_pmi.parquet`: локальная со-встречаемость в рамках одной публикации ($\mathrm{PMI} > 0$).
2. $W_{\mathrm{pools}}$ из `tag_co_from_pools.parquet`: глобальная со-встречаемость в рамках модерируемых тематических альбомов.

Суммарный взвешенный граф:
$$W_{ij} = W_{\mathrm{pmi}}(i, j) + \alpha \cdot W_{\mathrm{pools}}(i, j), \quad \alpha = 0.5$$

### 2.2. Построение матрицы сдвинутого PPMI (Shifted PPMI)
Для симметричного взвешенного графа вычисляются взвешенные степени вершин $d_i$ и полная сумма весов $S$:
$$d_i = \sum_{j} W_{ij}, \qquad S = \sum_{i < j} W_{ij}$$

Элементы разреженной матрицы $X \in \mathbb{R}^{V \times V}$ вычисляются как положительная поточечная взаимная информация со сдвигом:
$$X_{ij} = \max\left(0,\; \ln \frac{W_{ij} \cdot S}{d_i \cdot d_j} - \text{shift}\right)$$
где $\text{shift} \ge 0$ выступает аналогом числа негативных примеров $k$ в Word2Vec ($\text{shift} = \ln k$).

### 2.3. Спектральная факторизация (Truncated SVD)
К разреженной матрице $X$ в формате CSR применяется усеченное сингулярное разложение ранга $D = 128$:
$$X \approx U \Sigma V^T$$
Поскольку граф ненаправленный и матрица $X$ симметрична, левые и правые сингулярные векторы совпадают ($U = V$).
Для вычисления используется ARPACK (`scipy.sparse.linalg.svds`) с отказоустойчивым переключением на рандомизированный алгоритм Халко-Троппа (`sklearn.utils.extmath.randomized_svd`).

### 2.4. Формирование эмбеддингов и L2-нормализация
Координаты тегов масштабируются квадратным корнем сингулярных чисел (собственных значений):
$$E_{\mathrm{raw}} = U \cdot \Sigma^{1/2} \in \mathbb{R}^{V \times D}$$
Каждый вектор построчно проецируется на единичную гиперсферу (L2-нормализация):
$$e_i = \frac{E_{\mathrm{raw}}[i, :]}{\|E_{\mathrm{raw}}[i, :]\|_2 + \varepsilon}$$

## 3. Вычисление k-NN графа сходства через FAISS

Благодаря единичной L2-норме косинусное сходство между тегами тождественно равно скалярному произведению:
$$\mathrm{CosineSim}(e_i, e_j) = \frac{e_i \cdot e_j}{\|e_i\| \|e_j\|} \equiv e_i \cdot e_j$$

Для поиска ближайших соседей используется библиотека **FAISS** (Facebook AI Similarity Search):
- Инициализируется индекс точного поиска по скалярному произведению `faiss.IndexFlatIP(D)`.
- Индекс заполняется C-contiguous массивом векторов типа `float32`.
- Выполняется пакетный параллельный поиск `index.search(E, k + 1)`.
- Элемент с максимальным сходством (сам вектор запроса с косинусом $1.0$) отфильтровывается, оставляя $k$ истинных соседей.

## 4. Артефакты модуля
1. `features/tag2vec.parquet`: Таблица `[tag_id: Int32, vec: List[Float32]]`.
2. `features/tag2vec_knn.parquet`: Таблица k ближайших тегов `[tag_id: Int64, nn_tag_id: Int64, sim: Float64]`.
3. `features/tag2vec_meta.json`: Метаданные обучения (размерность, пороги частотности, спектр сингулярных чисел $\sigma_1 \dots \sigma_{16}$).
