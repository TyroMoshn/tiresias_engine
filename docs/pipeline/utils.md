# Модуль `utils.py` (Техническая документация)

## 1. Назначение
Модуль `utils.py` содержит базовые вспомогательные функции ввода-вывода, управления кэшированием (идемпотентность артефактов) и низкоуровневые алгоритмы сжатия целочисленных последовательностей (Variable-length Quantity / LEB128 и Delta-кодирование).

## 2. Архитектура и функции

### 2.1. Логирование и файловая система
- `log(msg: str) -> None`:
  Выводит сообщение в стандартный поток вывода с временной меткой в формате `[HH:MM:SS] msg`.
- `ensure_dir(p: Path) -> None`:
  Гарантирует существование директории `p`, рекурсивно создавая родительские каталоги (`mkdir(parents=True, exist_ok=True)`).

### 2.2. Управление свежестью артефактов (Идемпотентность)
- `newer_than(out: Path, *ins: Path) -> bool`:
  Проверяет временные метки последней модификации файлов (`st_mtime`).
  - Возвращает `False`, если целевой файл `out` отсутствует.
  - Возвращает `True` тогда и только тогда, когда время модификации `out` больше или равно времени модификации каждого существующего входного файла `ins`.
  - Позволяет пропускать дорогостоящие вычисления (например, парсинг 5 ГБ CSV или построение SVD), если исходники не менялись.

### 2.3. Алгоритмы сжатия целых чисел (Varint и Delta-кодирование)
Используются в модуле `stats_stage.py` для сериализации списков Top-K постов в `.topkpack`.

- `encode_varint(n: int) -> bytes`:
  Реализация схемы кодирования переменной длины (Variable Byte / LEB128):
  - Число разбивается на 7-битные блоки (младшие биты первыми, Little-Endian).
  - Если для представления числа требуются следующие байты, старший 8-й бит (MSB) устанавливается в `1` (`0x80`).
  - У последнего байта старший бит равен `0`.
  - Эффективность: малые числа ($< 128$) кодируются ровно 1 байтом вместо 4 или 8 байтов стандартных `int32`/`int64`.

- `encode_varint_delta(sorted_ids: list[int]) -> bytes`:
  Комбинация разностного кодирования (D-gaps / Delta encoding) и Varint:
  - На вход принимается **строго отсортированный по возрастанию** список идентификаторов: $[x_0, x_1, x_2, \dots]$.
  - Вычисляются разности между соседними элементами: $\Delta_0 = x_0 - 0$, $\Delta_i = x_i - x_{i-1}$ (где $\Delta_i \ge 0$).
  - Каждая разность $\Delta_i$ кодируется с помощью `encode_varint`.
  - Теоретическое обоснование: так как разности между близкими ID публикаций значительно меньше абсолютных номеров постов ($6 \times 10^6$), средний размер дельты часто укладывается в 1–2 байта.
  - Результирующий бинарный буфер дает высокую степень сжатия плотных списков постов без накладных расходов на распаковку общими компрессорами (Zstandard/Gzip).

## 3. Временная и пространственная сложность
- `encode_varint`: $O(\log_{128} n)$ по времени, $O(1)$ по памяти.
- `encode_varint_delta`: $O(M)$ по времени и памяти, где $M = \text{len}(sorted\_ids)$.
